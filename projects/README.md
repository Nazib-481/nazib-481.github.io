# Nazibul Bangladesh Analytics Project Pack

This folder contains selected finance, business analytics, and university coursework files used by **MD Nazibul Islam Nazib**.

## Independent / Portfolio Projects

### 1. The Rising Cost of Living — Bangladesh Household Finance
- Focus: monthly cash flow, spending patterns, budgeting, and savings rate
- Data: synthetic Bangladesh household dataset for academic/portfolio use
- [Synthetic dataset](personal_finance_bangladesh_synthetic.csv) · [Excel project pack](Nazibul_Bangladesh_Analytics_Project_Pack.xlsx) · [Case study](case-studies.html#personal-finance)

### 2. Finding the Profit Behind the Sales — Retail Sales Analysis
- Focus: revenue, COGS, gross profit, margin, product/category, city, and channel
- Data: 600 synthetic Bangladesh retail transactions for academic/portfolio use
- [Synthetic dataset](retail_sales_bangladesh_synthetic.csv) · [Excel project pack](Nazibul_Bangladesh_Analytics_Project_Pack.xlsx) · [Case study](case-studies.html#sales-performance)

### 3. Inside ACI: Is the Business Getting Stronger? — ACI PLC Financial Analysis
- Focus: FY2020–FY2025 published financial information, profitability, margins, and ROE
- [Analysis dataset](aci_plc_financial_analysis_fy2020_fy2025.csv) · [Case study](case-studies.html#aci-analysis)

### 4. Planning for Uncertainty — Business Budget & Scenario Forecast
- Focus: base, best, and worst-case budgeting and profit/loss scenarios
- [Scenario dataset](business_budget_scenarios.csv) · [Excel project pack](Nazibul_Bangladesh_Analytics_Project_Pack.xlsx) · [Case study](case-studies.html#budget-forecast)
