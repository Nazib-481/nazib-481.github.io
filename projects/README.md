# Nazibul Bangladesh Analytics Project Pack

## Project 1 — Personal Financial Analysis (Excel)
Monthly income/expense analysis, budget planning, savings trends, savings-rate calculations and chart-ready data.

## Project 2 — Sales Performance Dashboard (Power BI)
600 synthetic Bangladesh retail transactions covering city, channel, product, category, quantity, discount, revenue, COGS and gross profit.

## Project 3 — Listed Company Financial Analysis
ACI PLC FY2020–FY2025 published company figures with derived gross margin, PAT margin and ROE.

## Project 4 — Business Budget & Scenario Forecast
Base, best and worst-case revenue/expense assumptions with profit/loss calculations.

Synthetic datasets are for academic/portfolio use and must not be presented as real company/customer data.
